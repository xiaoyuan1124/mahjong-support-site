欸打牌啊｜隱私權政策

最後更新：2026-08-28

適用範圍

本政策說明「欸打牌啊」如何處理帳號、好友、牌局與裝置資料。營運者名稱、地址與正式聯絡方式：TBD。

我們處理的資料

  • Email 與 Auth User ID：註冊、登入與帳號識別。
  • Player ID 與 Display Name：玩家識別、好友搜尋及牌局顯示。
  • 好友關係與確認狀態：好友及牌局確認流程。
  • 牌局歷史、分數與 Room activity：計分、紀錄、Career、Analytics、Ranking 與 Matchup。
  • 裝置上的 account-scoped cache：離線呈現與載入效能。

使用目的

僅為提供、維護與保護 App 功能，包括身份驗證、玩家與好友功能、牌局、歷史紀錄及戰績分析。

Supabase 服務

我們使用 Supabase 提供 Authentication、Database 及必要的 backend services。服務供應商僅為提供 App 必要服務處理資料，不出售個人資料，也不將資料用於第三方廣告或跨 App tracking。法律與供應商條款檢視：TBD。

保存與刪除

  • 帳號資料於帳號存在期間保存。
  • 你可以從 App Settings 直接發起永久刪帳。
  • 刪帳後登入帳號、個人資料與好友關係會依刪除流程移除或匿名化。
  • Player ID 會永久退休，不重新分配。
  • 已完成牌局可能以匿名形式保留，歷史畫面顯示「已刪除玩家」，以維持其他參與者戰績一致性。
  • 裝置上的 account-scoped cache 會在登出或刪帳時清理。
