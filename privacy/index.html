欸打牌啊｜隱私權政策

最後更新：2026-09-06

適用範圍

本政策說明「欸打牌啊」如何處理帳號、好友、牌局與裝置資料。如有隱私問題，請透過本頁聯絡信箱與開發者聯繫。

我們處理的資料

  • Email 與 Auth User ID：註冊、登入與帳號識別。
  • Player ID 與 Display Name：玩家識別、好友搜尋及牌局顯示。
  • 好友關係與牌局確認狀態：好友及牌局確認流程。
  • 牌局歷史、分數與 Room activity：計分、紀錄、Career、Ranking、Matchup 與使用者可見的戰績分析。
  • 「資料有誤」等牌局確認回覆：處理有爭議牌局與重新確認流程。
  • 裝置上的本機模式資料與 account-scoped cache：離線呈現與載入效能。

使用目的

僅為提供、維護與保護 App 功能，包括身份驗證、玩家與好友功能、牌局、歷史紀錄、牌局確認及戰績統計。

Supabase 服務

我們使用 Supabase 提供 Authentication、Database、Realtime 與必要的 backend services。Supabase 及其基礎設施可能處理提供服務、安全、rate limiting 與除錯所需的 request metadata，例如 IP address、user-agent 或 request logs，保存期間依服務供應商與方案設定而定。我們不出售個人資料，也不將資料用於第三方廣告或跨 App tracking。

保存與刪除

  • 帳號資料於帳號存在期間或提供服務所需期間保存。
  • 你可以直接從 App 內發起永久刪帳，不需要聯絡客服。
  • 刪帳後登入帳號、個人資料與好友關係會依刪除流程移除或匿名化。
  • Player ID 會永久退休，不重新分配。
  • 已完成牌局可能以匿名形式保留，以維持其他參與者戰績一致性。
  • App 可能在裝置保留本機模式資料或帳號專屬快取；登出本身不等同刪除所有本機資料。
