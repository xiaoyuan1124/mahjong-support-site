欸打牌啊｜Support

「欸打牌啊」是台灣麻將牌局計分、牌局紀錄與戰績分析工具。

常見問題

無法登入

確認網路與 Email／密碼；若剛註冊，請先完成 Email 驗證。若仍無法登入，請稍後重試。支援信箱：ruiyuan9311241110@gmail.com。

不登入可以使用嗎？

可以。未登入時可選擇「繼續使用本機模式」，使用本機牌局與快速記錄；好友、雲端同步與正式參與者確認等功能需要登入。

Player ID

Player ID 用於玩家搜尋與識別，請使用完整正確的 ID。

加好友

在好友功能以完整 Player ID 搜尋，依邀請與確認流程操作。

建立牌局

從 App 的開桌功能建立 Room，設定底／台並安排四位玩家後開始牌局。

牌局資料有誤

正式參與者可在牌局確認流程回報資料有誤。建立者修正需要重新確認的牌局資料後，參與者可再次確認；有爭議的牌局不應在完成重新確認前成為正式戰績。

刪除帳號

前往帳號區域的「刪除帳號」，完成確認後即可直接發起永久刪除，不需要聯絡客服。已完成牌局可能匿名保留，以維持其他參與者的歷史戰績一致性。
