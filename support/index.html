欸打牌啊｜Support

「欸打牌啊」是台灣麻將牌局計分、牌局紀錄與戰績分析工具。

常見問題

無法登入

確認網路與 Email／密碼，稍後重試。支援信箱：TBD SUPPORT EMAIL。

Player ID

Player ID 用於玩家搜尋與識別，請使用帳號設定中的正確 ID。

加好友

在好友功能以 exact Player ID 搜尋，依邀請與確認流程操作。

建立／加入牌局

從底部導航開桌，或使用房間代碼加入既有牌局。

計分

在牌局中記錄每手分數；完成後可於歷史與 Career 查看結果。

刪除帳號

前往「我的」→「帳號」→「刪除帳號」，完成雙重確認即可發起刪除。已完成牌局可能匿名保留。
